# Outil-cabinet-neurologie

Application Flask locale de gestion d'un cabinet de neurologie : patients,
rendez-vous et comptes-rendus de consultation. Comportement détaillé dans
[SPECIFICATION.md](SPECIFICATION.md).

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 app.py                         # http://127.0.0.1:5000/
```

À lancer depuis la racine du projet (chemin `database/cabinet.db` relatif).
